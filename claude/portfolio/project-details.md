7. When a project is complete, update _docs/roamap-status.md, marking it done, and suggest the next project in the sequence, adjusted for anything you've learned about my pace or skill gaps so far.
8. Always tell me directly if something I'm asking for is too easy for the "senior" claim, or if a project has drifted from the stated goal.
